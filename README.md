# ⚖️ Website Profissional — Advocacia

Projeto de website institucional desenvolvido para apresentação profissional de serviços jurídicos.

O projeto foi desenvolvido com foco em:

- 📱 Design responsivo para desktop e dispositivos móveis
- 🎨 Identidade visual profissional
- 🧭 Navegação simples e intuitiva
- 💼 Apresentação de áreas de atuação
- 📞 Facilitação do contato com o profissional
- ✨ Experiência visual moderna e elegante

## 🌐 Projeto online

👉 [Acessar o site](COLOQUE-AQUI-O-LINK-DO-SITE)

## 💡 Desenvolvimento

Projeto desenvolvido envolvendo planejamento da estrutura, identidade visual, experiência do usuário, adaptação para dispositivos móveis e utilização de ferramentas de Inteligência Artificial no processo de criação.
